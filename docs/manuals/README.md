# Bundled user manuals

The Simplified Chinese and English PDF manuals are copied unchanged from
`KSSOLV-Toolbox-Manual/dist/`. `SHA256SUMS` records the hashes of the actual
copied files. Refresh the PDFs and checksums together when publishing a new
manual edition; do not bundle the manual authoring project or build outputs.

The desktop Documentation and Help buttons open the PDF for the current locale
with the operating system's default application. Chinese locales use the
Simplified Chinese manual; other locales use the English manual. Online links
are handled by the browser portal.
