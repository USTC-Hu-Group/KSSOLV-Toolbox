# KSSOLV Toolbox 建模用户指南

建模工作区用于编辑分子和周期结构。预览不会修改已保存的项目；只有确认操作并保存后，
修改才会写入项目。建模 Tab 中显示的命令取决于当前文档和选择内容。

[English](modeling-user-guide.md)

## 开始建模

1. 新建 Structure 或 Molecule 文档，或导入受支持的结构文件。
2. 激活三维视图，应用会自动显示 **晶体建模** 或 **分子建模** Tab。
3. 选择原子或化学键，然后从建模 Tab 或右键菜单选择命令。
4. 检查预览和诊断信息，再确认修改。
5. 结构准备完成后保存项目。

每次确认的操作对应一个撤销步骤。取消预览不会改变结构。

## 视图和选择

- 单击选择；使用 Shift+单击扩展选择。
- 按 `B` 进行框选，按 `L` 进行套索选择。
- 按 `G` 移动，按 `R` 旋转；变换过程中按 `X`、`Y` 或 `Z` 约束轴。
- 按 `Ctrl/Cmd+Z` 撤销，按 `Shift+Ctrl/Cmd+Z` 重做。
- 按 `Esc` 取消当前工具，按 `?` 打开快捷键面板。

需要反复编辑同一组位点时，可以保存 Selection Set。对于周期结构，即使改变显示重复
范围，选择仍会关联到底层位点。

完整速查请参阅[建模快捷键图](images/modeling-shortcuts.svg)。

## 分子建模

### 草绘和连接关系

按 `S` 启动 3D Sketch。单击空白处可放置原子；从已有原子拖动可添加带键原子；拖到
另一个已有原子上，在几何有效时可建立化学键。草绘工具栏用于选择元素、键级和常见
环尺寸。

选中化学键后可以修改键级或删除键。**Set Atom Chemistry** 用于修改元素、形式电荷和
杂化提示。**Add Hydrogens** 与 **Remove Hydrogens** 根据显式连接关系工作；大幅修改
拓扑后，建议运行 **Diagnose Molecule**。

红色碰撞或过短键警告会阻止无效草绘，但不能代替对最终模型的完整化学检查。

### 几何编辑

使用 **Set Distance**、**Set Angle** 和 **Set Dihedral** 进行精确修改。依次选择两个、
三个或四个原子时，视图会按选择顺序显示相应测量值。测量工具也可以交互选取原子，
然后把目标值应用到单个原子、子树或片段。

**Clean Geometry** 用于改善明显的局部几何问题。**Optimize Geometry** 使用结果报告中
标明的通用分子模型，适合准备初始结构，不应用于预测最终平衡几何。重要结构仍应使用
适合该体系的方法弛豫。

片段可通过定义好的连接位点装配。用户片段和常用建模参数可在 Library Browser 中管理。

## 晶体、表面和界面

除非命令明确创建派生结构，晶体命令会保留周期信息。

- **Crystal Builder** 根据晶格、空间群、元素和非对称位点创建结构。
- **Make P1** 在保持笛卡尔几何的同时移除对称性约束。
- **Build Supercell** 修改模型；**Display Repeat** 只改变显示。
- **Point Defect Enumeration** 生成对称不等价的缺陷候选。
- **Surface Builder** 创建 slab，并可识别几何层。
- **Add Vacuum**、吸附位点和异质结构工具用于准备后续弛豫所需的表面或界面。

周期距离、角度和二面角工具会使用邻近的周期映像。开始计算前，应检查最终晶胞和原子
位置。

### 添加吸附质

需要 top、bridge 或 hollow 候选时，使用 **Adsorption Locator**。几何评分只用于筛选，
不是吸附能。可选的刚性 UFF 相互作用评分不包括结构弛豫、静电、成键、溶剂和温度效应，
只能用于排序初始构型。

按 `O` 可在三维视图中直接放置片段：

1. 选择内置片段、项目片段或用户片段。
2. 从表面原子拖动，放置片段锚点。
3. 调整方向和锚点距离，同时检查接触警告。
4. 按 `Enter` 或选择 **Apply**，作为一个可撤销操作提交。

交互放置的吸附质只是初始构型。在解释稳定性之前，应使用合适的物理模型对宿主和
吸附质进行弛豫。

## 高分子和非晶结构

高分子工具可根据内置或用户提供的重复单元构建链，支持多链、序列选择、端基和可复现
的随机构建。创建大型模型前，应先检查预计原子数。

非晶装填可以使用分子数或组分目标、密度、最短接触和受限区域。装填完成并不表示结构
已经平衡；将其作为物理模型前，需要进行适当的最小化、热处理和 NVT/NPT 平衡。

装填失败时，可降低目标密度或分子数、增大区域，或更换随机种子。存在未解决的近距离
接触、环穿刺或链互锁时，不应直接使用该结果。

## 历史、批量任务和恢复

历史区提供当前文档的撤销、重做和重置。Presets 与 Templates 可保存常用命令参数。
Modeling Jobs 用于运行时间较长的文件批处理，并独立于当前视图报告进度。

会话异常中断后，应用可能提供恢复数据。覆盖已有项目前，应先检查恢复结构。脚本化和
可复现操作请参阅 [Modeling API v1](modeling-api.md)。

## 故障排查

| 问题 | 检查内容 |
| --- | --- |
| 命令不可用 | 激活正确的文档，并选择命令要求的对象数量和类型。 |
| 预览已经过期 | 结构在创建预览后发生了变化；重新打开命令。 |
| 装填失败 | 降低密度或分子数、增大区域，或更换随机种子。 |
| 超出原子数限制 | 减小链长、超胞大小或搜索范围。 |
| 视图命令失败 | 确认原模型未被修改，并记录文件格式和复现步骤。 |
