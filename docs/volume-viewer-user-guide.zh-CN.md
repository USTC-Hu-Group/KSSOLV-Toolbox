# KSSOLV 三维体数据查看器用户指南

三维体数据查看器用于显示标量场，并可叠加原子结构。它支持 VASP `CHGCAR`/`CHG`、
Gaussian Cube 和 XCrySDen XSF 文件，也可以直接打开 gzip 压缩文件。

[English](volume-viewer-user-guide.md)

## 打开体数据

1. 在 Project Browser 中双击 **Volume**。
2. 选择受支持的文件。
3. 等待初始视图和数据摘要出现。

大网格可能先以较低显示分辨率打开，随后在后台加载完整数据。状态区域会显示进度或
GPU 降级原因。关闭文档或打开其他文件时，不再需要的后台工作会被取消。

## 浏览和检查

- 按住鼠标左键拖动可旋转。
- 滚轮可缩放，按住右键拖动可平移。
- 按空格键重新居中并适配缩放，不改变观察方向。
- 按 `I` 隐藏或显示摘要、数值分布图和工具栏。
- 双击体数据可查看笛卡尔位置、网格位置和插值数值。

**Value Distribution** 图显示当前通道的数值分布。在等值面模式中，单击图表可设置
附近的正或负阈值；在切片和直接体渲染模式中，单击会调整距离点击值最近的颜色范围
端点。

在 **Settings** 中可选择等值面、I/J/K 晶格方向切片或直接体渲染。结构叠加包括原子、
化学键、晶胞、配位多面体和晶格轴。

## 选择通道

- 非自旋 CHGCAR 通常包含 `total`。
- 自旋 CHGCAR 提供 `total`、`diff` 以及派生的 `up`/`down` 通道。
- 非共线 CHGCAR 提供磁化分量及其模长。
- Cube 文件可以包含一个或多个 dataset。
- XSF 中每个带标签的 Datagrid 都显示为独立通道；2D Datagrid 以切片模式打开。

CHGCAR 密度以 `1/Angstrom^3` 显示。Cube 的原点、轴单位和非正交网格根据文件内容解释。
切片遵循实际体素矢量，不会假定切片平面与笛卡尔轴对齐。

## 导出

- 使用相机按钮把当前视图导出为 PNG。
- 需要保存不含体素数组的场景设置时，可导出 JSON。
- 等值面模式可导出 glTF、GLB、PLY 或 STL 几何。
- 切片模式可把当前平面导出为 PNG 或 CSV。

除非导出对话框另有说明，导出的几何和坐标使用 Å 笛卡尔单位。

## 故障排查

- WebGL2 不可用时，可以使用 CPU 切片视图和 PNG/CSV 导出。
- GPU 无法容纳三维纹理时，查看器会回退到晶格切片并显示原因。
- 平滑浮点过滤不可用时，会使用 nearest sampling。
- 等值面没有三角形时，等待构建完成，或把阈值调整到数据范围内。
- WebGL context 丢失后，等待查看器重建；若持续失败，切换到等值面或切片模式。
- 维度无效、包含非有限数值或预计大小不安全的文件，会在大内存分配前被拒绝。

显示插值不会增加源数据的真实分辨率。需要定量空间细节时，应使用更高分辨率的计算数据。
