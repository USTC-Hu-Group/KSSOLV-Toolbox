# KSSOLV 建模示例项目

这些 `.ks` 文件由 `dev/modeling/generateModelingExamples.m` 在 MATLAB R2026b 中生成，并可通过 KSSOLV 的“打开项目”直接载入。

- `01-benzamide-builder.ks`：分子草绘、芳香环、键级与自动补氢。
- `02-pt111-surface.ks`：Fm-3m Pt 晶体到 Pt(111) slab 与真空层。
- `03-polymer-packing.ks`：PEO-PPO-PEO 嵌段共聚物及未平衡非晶装填。

所有示例都是可继续编辑的统一模型对象，而非静态截图。
